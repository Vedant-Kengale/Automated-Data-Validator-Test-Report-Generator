# Automated Data Validator & Test Report Generator

A C++ command-line tool that simulates automated test case execution and generates structured test reports. Built as part of my learning journey in software testing and quality assurance.

## 🎯 Project Overview

This project demonstrates:
- **File I/O operations** in C++ (reading/writing CSV files)
- **Data validation logic** (simulating test case execution)
- **Defect identification and reporting** (structured bug logging)
- **Test report generation** (Pass/Fail statistics)

## 🚀 How to Run

### On Linux/Ubuntu:
```bash
g++ test_validator.cpp -o validator
./validator
